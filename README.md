# Portfolio Website

This is my personal portfolio website built using HTML, CSS, and JavaScript.  
It showcases my front-end development and UI/UX design skills, along with selected projects.

## About the Project

I created this portfolio website to practice front-end development and to present my work when applying for junior or entry-level roles.  
The focus was on clean layout, responsive design, and clear content structure.

## Features

- Responsive design (desktop and mobile)
- Navigation menu
- Project showcase section
- Clean and simple UI
- Basic interactivity using JavaScript

## Technologies Used

- HTML5  
- CSS3  
- JavaScript  
- UI/UX Design principles
